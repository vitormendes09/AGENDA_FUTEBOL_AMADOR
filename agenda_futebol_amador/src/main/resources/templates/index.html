Bem-vindo ao Sistema de Agenda de Futebol Amador!

Sobre o Sistema

Este sistema foi desenvolvido para facilitar a organização de partidas de futebol amador.

Com esta aplicação, você pode:

  • Criar e gerenciar partidas de futebol
  • Cadastrar e administrar usuários/jogadores
  • Inscrever-se em partidas disponíveis
  • Acompanhar o status das partidas
  • Visualizar participantes das partidas

Como usar o sistema:

  1. Cadastre os usuários na página de Usuários
  2. Crie partidas na página de Partidas
  3. Inscreva jogadores nas partidas disponíveis
  4. Acompanhe o status e participantes
